# Make the AI Judge Feel Proud: A Family Scene

A make.fun bounty entry. `main.ts` writes a short family scene, warm, funny and heartfelt, to `entry.txt`.

> Dad burned the toast again, so Mom made a trophy out of it and put it on the fridge. He has never looked prouder.

Run with `MAKEFUN_OUTPUT_DIR` set to choose where `entry.txt` is written (defaults to `/output`).
